# `notebooks/` — Notebooks de Jupyter

Exploración de datos, preprocesamiento, entrenamiento y evaluación de modelos.

```text
notebooks/
├── 01_exploracion/       Análisis exploratorio (EDA)
├── 02_preprocesamiento/  Limpieza y anonimización
├── 03_entrenamiento/     Entrenamiento y ajuste de hiperparámetros
└── 04_evaluacion/        Métricas, equidad y deriva
```

## Reglas

1. Los notebooks son para **explorar**; el código que pasa a producción se mueve a `src/`.
2. La numeración indica el orden de lectura.
3. Antes de publicar un notebook, limpiar las salidas con datos sensibles.
